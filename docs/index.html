    @playform/document - v0.1.6

    Document 📃

    Document all your TypeScript files using TypeDoc.

    Installation 🚀

    Add configuration and setup scripts:

    npm install -D -E @playform/document

    Usage 🛠️

    package.json

    {
    	"scripts": {
    		"Document": "Document 'Source/**/*.ts'"
    	}
    }

    CLI Usage

    Document 'Source/**/*.ts'
